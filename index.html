Pengaturan Gemini API Key

Kunci API disimpan secara lokal di browser perangkat Anda melalui localStorage dan langsung berkomunikasi ke endpoint resmi Google tanpa perantara server.

Cara Mendapatkan API Key Gratis:
  1. Kunjungi portal aistudio.google.com dan masuk dengan akun Google.
  2. Klik menu Get API key di panel navigasi sebelah kiri.
  3. Pilih Create API key > Create API key in new project.
  4. Salin string API key yang berawalan AIzaSy..., lalu tempel pada kotak input di atas.
